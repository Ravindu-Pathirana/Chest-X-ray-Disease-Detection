# T35 efficiency — measured scope and remaining work

The repository now has an eight-row, single-session **architecture-only CPU**
benchmark at `artifacts/T35_efficiency/architecture_only_efficiency.csv`,
generated by `scripts/run_t35_efficiency.py`. It covers A0 and the comparison
arm for DenseNet121, ResNet50, EfficientNet-B0 and ViT-Base/16. The ViT class
was reconstructed from the T26 notebook and has passed forward-path tests;
it has **not** yet been strict-loaded against a T26 checkpoint. ViT A2 is a
provisional architecture comparison, not a declared T26 winner.

| Backbone | A0 parameters | Module-arm parameters | A0 CPU ms | Module-arm CPU ms |
|---|---:|---:|---:|---:|
| DenseNet121 | 6,957,956 | 7,089,285 | 190.4 | 193.4 |
| ResNet50 | 23,516,228 | 24,041,029 | 145.7 | 157.5 |
| EfficientNet-B0 | 4,012,672 | 4,115,233 | 59.9 | 63.0 |
| ViT-Base/16 | 85,801,732 | 85,875,653 | 316.7 | 311.3 |

These are 224×224, batch-1, random-initialisation models on one Windows CPU
with PyTorch 2.14.0+cpu, five warmups and 20 timed passes per model. The full
hardware record is in `architecture_only_hardware.json`. Small latency
differences should not be interpreted as stable speedups or regressions from
one short run; no paired uncertainty interval was measured. The CSV includes
state-dict sizes, but checkpoint-file sizes are missing where weights were not
loaded.

`fvcore` reported unsupported operations, including fused ViT attention.
Its GFLOP column is therefore a **partial estimate**, not a complete count.
Parameter counts are exact for the constructed architectures.

T35 is **not complete**. To close it, strict-load all eight intended
checkpoints, confirm the ViT wrapper matches the supplied weights, benchmark
all models in a single GPU session with the same input shape/batch size and
warmup/timed-pass protocol, record GPU model/device and software versions,
checkpoint sizes and peak memory, and review FLOP handling of unsupported
operators. Do not combine prior per-backbone latency numbers from different
sessions as if they were a controlled comparison.
